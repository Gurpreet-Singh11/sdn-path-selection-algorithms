# SDN Path-Selection Algorithm Comparison

Comparative evaluation of four path-selection algorithms in
Software-Defined Networks using Mininet and OpenFlow.

## Algorithms
- Round-Robin
- Least-Utilized
- ECMP (Equal-Cost Multi-Path)
- Weighted-History

## Results

| Method | Avg Switches | Stability |
|---|---|---|
| Round-Robin | 24.3 | 3.9% |
| Least-Utilized | 1.0 | 96.1% |
| ECMP | 0.0 | 100.0% |
| Weighted-History | 1.0 | 96.1% |
